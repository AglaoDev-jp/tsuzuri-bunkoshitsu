# 綴り文庫室 v4 利用マニュアル

**「選択で綴る、偶然の物語。」**

「綴り文庫室（つづりぶんこしつ）」は、このPC上のAIが毎回新しい物語を作るテキストアドベンチャーゲームです。全5場面で2つの行動から1つを選び、GOOD ENDを目指します。BAD ENDになっても、同じ場面へ戻って再挑戦できます。

このマニュアルはWindows実行ファイル版用です。遊び方は本書だけで確認できます。配信・再利用の条件は、同梱の [GUIDELINE.md](./GUIDELINE.md) と `licenses/` もご確認ください。


---

## ゲームの特徴

- Ollamaを利用し、ローカルLLMが物語を生成
- 30種類の登録ジャンル
- 文章で物語を指定できる「自由に綴る」モード
- 1ゲームは全5場面
- 各場面に2つの選択肢ボタン
- 正しい選択肢を選ぶと次の場面へ進行
- 誤った選択肢を選ぶと、その場面専用のBAD END
- BAD END後は同じ選択肢へ戻って再挑戦可能
- 最終場面の正解でGOOD END
- クリア後にエピローグ、GAME CLEAR、AI COMMENT、プレイ記録を表示
- 場面に応じた背景画像を表示する「情景窓」
- AIが場面に合う背景タグ・BGMタグを選択
- BGM・SE・VOICEの音量を個別に調整可能
- VOICEVOXによる読み上げに対応
- バックログの閲覧、プレイ記録と読み上げ音声の保存
- 物語生成が停止した場合の生成キャンセル

AIが場面を順番に生成するため、同じジャンルを選んでも、プレイするたびに登場人物や展開、結末が変化します。

## 1. 必要なもの

- WindowsのPC（Windows 11を想定）。Pythonのインストールは不要です。
- [Ollama](https://ollama.com/) と、ダウンロード済みのローカル実行用モデル。
- 読み上げを使う場合だけ、[VOICEVOX](https://voicevox.hiroshiba.jp/) と音声を再生できる環境。

必要なメモリ・VRAMや生成時間は、選ぶモデルとPC性能で変わります。モデル等の初回ダウンロードにはインターネット接続が必要です。初期設定は、このPC上のOllamaとVOICEVOXへ接続します。外部サービスやクラウドモデルを選んだ場合まで、通信がPC内だけに収まることを保証するものではありません。

## 2. 最初の準備と起動

### Ollamaとモデルを準備する

1. [Ollama公式サイト](https://ollama.com/)からWindows版をインストールし、起動します。
2. Windowsのターミナルまたはコマンドプロンプトを開き、次を実行します。

```text
ollama pull gemma3:4b
```

`gemma3:4b` はゲームの初期モデルです。別の導入済みモデルも画面から選べます。日本語で文章を生成でき、ゲーム用の決まった形式にも応答できるモデルを使用してください。

導入済みモデルを確認するコマンド：

```text
ollama list
```

### VOICEVOXを準備する（任意）

[VOICEVOX公式サイト](https://voicevox.hiroshiba.jp/)からインストールし、読み上げを使う前に起動してください。読み上げが不要なら、導入しなくても遊べます。　　

> [!NOTE]
> モデルによって、必要なメモリ、生成速度、日本語性能、JSON形式の指示への従いやすさが異なります。動作が重い場合は、より軽量なモデルをお試しください。
> Ollama、モデル、VOICEVOX本体はゲームに同梱されていません。

### ゲームを起動する

1. 作者の[配布ページ](https://github.com/AglaoDev-jp/tsuzuri-bunkoshitsu/releases)からWindows実行ファイル版を入手し、バージョンを確認します。
2. ZIPを右クリックして「すべて展開」し、書き込み可能な任意のフォルダへ展開します。
3. Ollamaを起動し、必要ならVOICEVOXも起動します。
4. 展開先の `綴り文庫室.exe` をダブルクリックします。

**ZIPの中から直接実行せず、展開した配布フォルダ全体を保持してください。** `綴り文庫室.exe` の隣の `_internal/` は実行に必要です。ファイル名の変更や、exeだけの移動は避けてください。

> 初回起動時にWindowsやセキュリティソフトの確認画面が表示される場合があります。配布元とファイルを確認したうえで実行してください。


## 3. ゲーム開始前の設定

| 画面の項目 | 操作 |
| --- | --- |
| ジャンル | 30種類から選びます。希望を文章で指定したいときは末尾の「自由に綴る」を選びます |
| モデル | 導入済みのOllamaモデルを選びます。初期モデルは `gemma3:4b` です |
| モデル更新 | Ollama起動後やモデル追加後に、モデル一覧を取り直します |
| VOICEVOX読み上げ | 読み上げを使うときにONにします。起動直後はOFFです |
| 話者ID | 使用したい声のIDを半角数字で入力します。初期値は `3` です |
| BGM音量・SE音量・VOICE音量 | 音楽・効果音・読み上げをそれぞれ0～100で調整します |
| 音声計測 | 必要な場合だけ使う補助機能です。通常のプレイには不要です |

別の声を使う場合は、VOICEVOX公式の[話者一覧](https://voicevox.hiroshiba.jp/)やエンジンの話者情報で、キャラクター・スタイルとIDの対応を確認してください。IDにはキャラクター名を入力しません。

音量の初期値はBGM・SEが20、VOICEが100です。音量調整は再生中にも反映されます。画面で変更した設定は、アプリを終了すると自動保存されません。

## 基本的な遊び方

### 1. ジャンルを選ぶ

ジャンル欄から、遊びたい物語を選びます。v4には次の30ジャンルが登録されています。

- 王道ファンタジー
- 恋愛告白
- 明るいミステリー
- 怪談
- モンスターサバイバル
- 宇宙SF
- 異世界転生
- 刑事ドラマ
- シリアスドラマ
- コメディ
- ゾンビパニック
- 青春部活
- 無人島サバイバル
- 探検隊
- 海賊冒険
- 忍者
- スパイアクション
- タイムトラベル
- 昭和レトロ冒険
- 法廷ドラマ
- お仕事体験
- 学園七不思議
- 西部劇
- 日常の不思議
- 旅情ドラマ
- 時代劇
- 探偵ミステリー
- 料理チャレンジ
- 格闘アクション
- ラブコメ

### 2. モデルを選ぶ

Ollamaにインストールされているモデルから、物語生成に使用するモデルを選びます。  
Ollamaを起動したあとにモデルを追加・削除した場合は、「モデル更新」を押してください。

> 初期設定は gemma3:4b です。
> 本アプリは、場面データをJSON形式で受け取ります。日本語生成ができても、JSON形式の指示へ安定して従えないモデルでは、生成を再試行したり、開始に失敗したりする場合があります。
> 大きなモデルほど必ず快適になるとは限りません。PCのメモリやVRAMに合ったモデルを選んでください。

### 3. 音声設定を確認する

VOICEVOXを使用する場合は、VOICEVOXを起動し、「VOICEVOX読み上げ」をONにします。音声が不要な場合はOFFにしてください。

必要に応じて、BGM・SE・VOICEの音量も調整します。

### 4. 「ゲーム開始」を押す

AIが第1場面を生成します。生成中は、次のような待機メッセージが表示されます。

```text
物語を生成しています...
```

点の数が変化しますが、正確な進捗率を示すものではありません。

### 5. 場面を読む

場面は、次のような形式で表示されます。

```text
--- 場面 1 / 5 ---
【場面タイトル】

物語の本文
```

選択肢は、本文欄ではなく画面下部の2つのボタンへ表示されます。

### 6. 選択肢ボタンを押す

本文の表示が完了すると、A・Bの選択肢ボタンが操作可能になります。選びたい行動のボタンをクリックしてください。

キーボードで `a`・`b` を入力する必要はありません。

### 7. 5場面目の正解を目指す

正しい選択を重ね、5場面目で正解するとGOOD ENDです。GOOD ENDのあとに、エピローグやAI COMMENTなどを順番に読み進めます。

## 「自由に綴る」で始める

ジャンル欄の末尾にある「自由に綴る」を選ぶと、普段は物語が表示される場所が専用の複数行入力欄へ切り替わります。

入力欄へ、遊びたい物語を一文または数文で自由に書いてください。ジャンル、舞台、主人公、雰囲気、目的などを個別の入力欄へ分ける必要はありません。

入力できる長さは1000文字までです。現在の文字数は入力欄の下に表示されます。

入力後は、通常モードと同じ「ゲーム開始」を押します。AIが入力内容を全5場面のゲーム向けに整理してから、第1場面を生成します。そのため、通常ジャンルより開始時のAI処理が1回多くなります。

開始設定や第1場面の生成に失敗した場合は、入力内容を残したまま専用画面へ戻ります。文章を修正して再試行できます。

生成中に「生成キャンセル」を押した場合も、入力内容は保持されます。

> [!NOTE]
> 自由入力欄でEnterキーを押すと、通常どおり改行できます。本文表示中のEnter操作とは区別されています。

---


## キーボード操作

Enterキーの動作は、現在の状態によって変わります。

| 状態 | Enterキーの動作 |
| --- | --- |
| 「自由に綴る」の入力欄を編集中 | 入力欄内で改行します |
| 本文をタイピング表示中 | 読み上げを停止し、残りの文章をすぐに全文表示します |
| 本文が全文表示済みで読み上げ中 | 残っている読み上げを停止します |
| 本文と選択肢の表示完了後 | 選択肢は画面上のボタンで決定します |
| AIが場面を生成中 | 完了するまで選択操作は行えません |

Enterキーを押しても、場面や選択結果が飛ばされることはありません。

---


## タイピング表示と音声

本文は1文字ずつ表示されます。読点、句点、改行では、通常の文字より少し長めの間を取ります。

VOICEVOX読み上げがONの場合は、最初の音声チャンクが完成してからタイピング表示と音声再生を開始します。後続の音声は順次準備されます。

本文の表示が完了するまでは、選択肢ボタンを押せません。

「音声停止」またはEnterキーで読み上げを停止しても、テキスト表示とゲーム進行は続けられます。

---


## 正解後の進み方

正しい選択肢を押すと、選んだ行動によって起きた結果が表示されます。

結果文の表示と読み上げが完了すると、選択肢欄に「次のシナリオへ」ボタンが表示されます。このボタンを押すまで、次の場面は表示されません。

自動で場面が切り替わらないため、結果文を読み終えてから、自分のタイミングで次へ進めます。

---


## BAD ENDと再挑戦

誤った選択肢を選ぶと、その場面の選択内容に対応したBAD ENDが表示されます。

```text
=== BAD END ===
BAD ENDタイトル

その選択によって起きた結末
```

BAD END後は、次のどちらかを選べます。

### 「直前の選択肢へ」

BAD ENDになった場面へ戻り、もう一度2つの選択肢から選び直します。

- 場面本文は再生成されません。
- 選択肢も同じ内容です。
- 直前の状況を確認しながら、別の選択を試せます。
- その場面用の読み上げ音声が残っている場合は、再挑戦時に利用されます。

### 「最初から」

現在の進行を終了し、第1場面から新しいゲームを始めます。

AIが物語を新しく生成するため、前回とは異なる展開になることがあります。

---


## GOOD ENDとAI COMMENT

5場面目で正しい選択をすると、次の内容が順番に表示されます。

1. GOOD END
2. EPILOGUE
3. GAME CLEAR
4. AI COMMENT
5. PLAY RECORD
6. 終了案内

GOOD ENDは「正解側の正規クリアエンディング」です。物語に応じて、大団円だけでなく、ほろ苦い結末、静かな別れ、代償を伴う勝利、余韻の残る結末などになる場合があります。

各項目は自動では進みません。次のボタンを順番に押して読み進めます。

- 「エピローグへ」
- 「GAME CLEAR」
- 「AI COMMENT」
- 「PLAY RECORD」
- 「最後に」

PLAY RECORDには、次の情報が表示されます。

- プレイ判定
- バッドエンド到達回数
- 「直前の選択肢へ」戻った回数
- 総選択回数

AI COMMENTは、物語とプレイ記録をもとに、今回の選択や展開をゲームマスターが短く振り返る文章です。

追加エンディングの生成に失敗した場合でも、固定メッセージへ切り替わり、ゲームはクリア扱いで終了します。

---

## 5. バックログとプレイ記録の保存

### バックログ

「バックログ」で、それまでに表示を終えた本文・選択結果・エンディングを別ウィンドウで読めます。新しいゲームを始めると前回分は消えます。

### テキスト保存

**最後の終了案内まで表示が完了した後**に「テキスト保存」を押し、保存先とファイル名を指定します。開始日時・ジャンル・使用モデル・バックログ全文をテキストで保存します。

初期ファイル名は `綴り文庫室_プレイ記録_YYYYMMDD_HHMMSS.txt` です（末尾は保存日時）。

> 途中から再開するためのセーブデータではありません。

### 音声保存

クリア後、生成した読み上げ音声がある場合に「音声保存」を使えます。

1. 「音声保存」を押します。
2. 新しく作るフォルダの名前を入力します。
3. 保存先となる親フォルダを選びます。

WAVファイルを、場面・区間に基づく連番付きで保存します。再挑戦時の音声や、準備したものの再生しなかった音声が含まれる場合があります。BGM・効果音は保存対象に含みません。同名フォルダがある場合は別名を指定してください。

残したい記録と音声は、**「最初から」やアプリ終了の前に保存**してください。未保存の読み上げ音声は、次のゲームや終了時などに消去されます。

## トラブルシューティング

### Ollamaに接続できない

確認事項：

1. Ollamaがインストールされているか
2. Ollamaが起動しているか
3. `ollama serve` を実行できるか
4. 使用するモデルがダウンロード済みか
5. 接続先が `http://127.0.0.1:11434` になっているか

### モデル一覧が表示されない

1. Ollamaを起動します。
2. `ollama list` でモデルを確認します。
3. アプリの「モデル更新」を押します。

必要なモデルがない場合：

```bash
ollama pull gemma3:4b
```

### 場面生成が遅い

対処例：

- より軽量なモデルを選ぶ
- PC上の負荷が高いアプリを終了する
- Ollamaを再起動する
- VOICEVOX読み上げをOFFにして待ち時間を比較する

「自由に綴る」は、開始時に入力内容をゲーム設定へ整理するため、通常ジャンルよりAI処理が1回多くなります。

生成を待ち続けられない場合は、「生成キャンセル」で初期状態へ戻れます。

### 生成を何度もやり直している

モデルが、ゲームで必要なJSON形式を正しく返せていない可能性があります。

対処例：

- JSON形式の指示へ従いやすいモデルへ変更する
- Ollamaを再起動する
- 「自由に綴る」の入力を短く整理する

内部の再試行上限は、初期設定で3回です。

### 「自由に綴る」でゲームを開始できない

確認事項：

- 入力欄が空になっていないか
- 1000文字を超えていないか
- 選択したモデルがOllamaで利用できるか
- モデルがJSON形式の指示へ対応できるか

エラー後も入力内容は保持されます。文章を修正して再試行してください。

### VOICEVOXに接続できない

確認事項：

1. VOICEVOXがインストールされているか
2. VOICEVOXが起動しているか
3. 「VOICEVOX読み上げ」がONか
4. 接続先が `http://127.0.0.1:50021` になっているか

VOICEVOXに接続できなくても、テキストのみでゲームを続けられます。

### 音声が再生されない

確認事項：

- PCがミュートになっていないか
- 正しい音声出力先が選ばれているか
- 話者IDが半角数字か
- 指定した話者IDが存在するか
- Pythonソース版では `pygame` がインストールされているか
- VOICE音量が0になっていないか

### BGM・効果音が再生されない

確認事項：

- BGM音量またはSE音量が0になっていないか
- `src/assets/bgm/` と `src/assets/sfx/` に音源が存在するか
- 音源のファイル名を変更していないか
- PCの音声出力が正しく設定されているか

音源が見つからない場合でも、ゲームは続行します。

### 読み上げ開始まで時間がかかる

本アプリは、最初の音声チャンクが完成してから本文表示と再生を始めます。

初回生成、文章の長さ、使用する話者、PC性能によっては、待機表示がしばらく続く場合があります。

音声が不要な場合は、「VOICEVOX読み上げ」をOFFにすると、音声生成を待たずに遊べます。

### Enterキーで選択肢を決定できない

Enterキーは、本文の全文表示または音声停止に使用します。選択肢の決定には、画面下部のA・Bボタンを使用してください。

### 「次のシナリオへ」が表示されない

正解結果のタイピング表示と、VOICEVOX読み上げがONの場合は読み上げ処理の完了を待ってください。

読み上げを待たずに進みたい場合は、「音声停止」を押してください。

### テキスト保存・音声保存が押せない

保存機能は、最後の終了案内まで表示してゲームクリア処理が完了したあとに有効になります。

音声保存は、VOICEVOXで生成されたWAVファイルが存在する場合だけ有効になります。

### 追加エンディングの生成に失敗した

エピローグやAI COMMENTの追加生成に失敗した場合は、固定メッセージへ切り替わります。GOOD ENDまでの進行は失われず、ゲームはクリア扱いで終了します。
