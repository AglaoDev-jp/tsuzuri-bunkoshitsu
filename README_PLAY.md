# 綴り文庫室 v2 利用マニュアル
**"選択で綴る、偶然の物語。"**   

**Ollama + VOICEVOXで遊ぶ、ローカルAIテキストアドベンチャーゲーム**  

「綴り文庫室」は、ローカル環境のAIがプレイごとに短い物語を作るテキストアドベンチャーゲームです。

全5場面で表示される2つの選択肢ボタンから行動を選び、GOOD ENDを目指します。誤った選択でBAD ENDになっても、同じ場面へ戻って再挑戦できます。

> [!NOTE]
> 本マニュアルは、アプリのソースコードおよび仕様をもとに、OpenAIの対話型AI「ChatGPT」の支援を受けて草案を作成し、作者が内容の確認・編集を行っています。
> 本ソフトウェアは、同名または類似名称の既存の商標・製品・サービスとは関係ありません。

## ゲームの特徴

- AIが選択したジャンルに沿って物語を生成
- 1ゲームは全5場面
- 各場面に2つの選択肢ボタン
- 正しい選択肢を選ぶと次の場面へ進行
- 誤った選択肢を選ぶと、その場面専用のBAD END
- BAD END後は同じ選択肢へ戻って再挑戦可能
- 最終場面の正解でGOOD END
- クリア後にエピローグ、プレイ記録、AI COMMENTを表示
- VOICEVOXによる読み上げに対応
- 場面に応じた背景画像を表示する「情景窓」
- AIが場面に合う背景タグ・BGMタグを選択
- BGM・SE・VOICEの音量を個別に調整可能
- 物語生成が停止した場合に、生成をキャンセルして初期状態へ戻る機能

AIが場面を順番に生成するため、同じジャンルを選んでも毎回新しいストーリーが楽しめます。

## 動作環境

### 必須

- Ollama
- Ollamaにダウンロード済みのモデル

実行ファイル版ではPythonとPythonライブラリは不要です。Pythonソース版を使用する場合は、Python 3.10以上、`requests`、`pygame`が必要です。

### 音声読み上げを使用する場合

- VOICEVOX
- 音声を再生できる環境

VOICEVOXを使用しない場合でも、テキストのみでゲームを遊べます。

## セットアップ

### 1. Ollamaをインストールする

[Ollama公式サイト](https://ollama.com/)からOllamaをインストールしてください。

---

### 2. 使用するモデルをダウンロードする

初期設定では、次のモデルが選択されます。

```text
gemma3:4b
```

モデルのダウンロード例：

```bash
ollama pull gemma3:4b
```

インストール済みモデルは、次のコマンドで確認できます。

```bash
ollama list
```

> [!NOTE]
> モデルによって、必要なメモリ、生成速度、日本語性能、指示への従いやすさが異なります。動作が重い場合は、より軽量なモデルをお試しください。

---

### 3. Ollamaを起動する

通常は、Ollamaを起動した状態で本アプリを使用します。

OllamaのAPIは、初期設定では次のアドレスで動作します。

```text
http://localhost:11434
```

接続できない場合は、ターミナルまたはコマンドプロンプトで次のコマンドを実行してください。

```bash
ollama serve
```

---

### 4. VOICEVOXをインストールする（任意）

音声読み上げを使用する場合は、VOICEVOXをインストールしてください。

- [VOICEVOX公式サイト](https://voicevox.hiroshiba.jp/)
- [VOICEVOX GitHub](https://github.com/VOICEVOX/voicevox)

VOICEVOX ENGINEは、初期設定では次のアドレスで動作します。

```text
http://127.0.0.1:50021
```

本アプリにVOICEVOX本体は含まれていません。読み上げを使用するときは、VOICEVOXを本アプリより先に起動してください。

---

### 5. Pythonライブラリをインストールする（Pythonソース版のみ）

ターミナルまたはコマンドプロンプトで、次のコマンドを実行してください。

```bash
python -m pip install requests pygame
```

WindowsのPython Launcherを使用する場合：

```bash
py -m pip install requests pygame
```

`tkinter`は通常、Pythonに同梱されています。

---

### 6. 必要なファイルを配置する（Pythonソース版のみ）

次のファイルを同じプロジェクト内に配置してください。

```text

├─ main.py
├─ game_engine.py
├─ game_prompts.py
├─ llm_client.py
├─ voicevox_client.py
```

`data/game_settings.json`が存在しない場合や、JSONの書式が正しくない場合は、正常に起動できません。

## 起動方法

本アプリは、**実行ファイル版**と**Pythonソース版**のどちらからでも起動できます。

### 実行ファイル版から起動する

1. GitHub ReleasesからWindows版のZIPファイルをダウンロードします。
2. ZIPファイルを任意の場所へ展開します。
3. Ollamaを起動します。
4. 音声読み上げを使用する場合は、VOICEVOXも起動します。
5. 展開したフォルダ内の `綴り文庫室.exe` をダブルクリックします。

```text
綴り文庫室/
├─ 綴り文庫室.exe
└─ _internal/
```

> [!IMPORTANT]
> `綴り文庫室.exe`だけを別の場所へ移動せず、`_internal`フォルダと同じ配布フォルダ内で起動してください。

実行ファイル版では、PythonおよびPythonライブラリを別途インストールする必要はありません。ただし、物語生成にはOllamaとダウンロード済みモデルが必要です。VOICEVOXは任意です。

初回起動時にWindowsやセキュリティソフトの確認画面が表示される場合があります。配布元とファイルを確認したうえで実行してください。

### Pythonソース版から起動する

`main.py`のあるフォルダで、次のコマンドを実行します。

```bash
python main.py
```

WindowsのPython Launcherを使用する場合：

```bash
py main.py
```

正常に起動すると、「綴り文庫室」のウィンドウが表示されます。

起動直後は、ジャンルとモデルを選び、「ゲーム開始」を押します。

主な操作項目は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| ジャンル | 生成する物語の種類を選びます |
| モデル | Ollamaにインストールされているモデルから、物語生成に使用するモデルを選びます |

| 話者ID | VOICEVOXで使用する声のIDを半角数字で指定します |

| 読み上げ停止 | 再生中および待機中の読み上げを停止します |
| BGM音量 | BGMの再生音量を調整します |
| SE音量 | 効果音の再生音量を調整します |
| VOICE音量 | VOICEVOX読み上げ音量を調整します |

* 明るいミステリー
* 怪談
* モンスターサバイバル
* 宇宙SF
* 異世界転生
* 刑事ドラマ
* シリアスドラマ
* コメディ
* ゾンビパニック
* 青春部活
* 無人島サバイバル
* 探検隊
* 海賊冒険
* 忍者
* スパイアクション
* タイムトラベル
* 昭和レトロ冒険
* 法廷ドラマ
* お仕事体験
* 学園七不思議
* 西部劇
* 日常の不思議
* 旅情ドラマ
* 時代劇
* 探偵ミステリー
* 料理チャレンジ
* 格闘アクション
* ラブコメ

ジャンル名と説明は、`data/game_settings.json`の`genres`から追加・編集できます。

### 2. モデルを選ぶ

Ollamaにインストールされているモデルから、物語生成に使うモデルを選びます。

### 3. 音声設定を確認する

VOICEVOXを使用する場合は、VOICEVOXを起動し、「VOICEVOX読み上げ」をONにします。

音声が不要な場合は、読み上げをOFFにしてください。

### 4. 「ゲーム開始」を押す

AIが最初の場面を生成します。生成中は、次のような待機メッセージが表示されます。

```text
物語を生成しています...
```

点の数が変化しますが、正確な進捗率を示すものではありません。

### 5. 場面を読む

場面は、次のような形式で表示されます。

```text
--- 場面 1 / 5 ---
【場面タイトル】

物語の本文

a. 選択肢A
b. 選択肢B
```


### 6. 選択肢ボタンを押す

本文と選択肢の表示が完了すると、画面下部に2つの選択肢ボタンが表示されます。

選びたい行動のボタンをクリックしてください。キーボードで `a`・`b` を入力する必要はありません。

正しい選択なら結果文が表示され、次の場面が生成されます。誤った選択なら、その場面に対応したBAD ENDになります。

### 7. 5場面目の正解を目指す

5場面目で正しい選択をするとGOOD ENDです。物語本編の結末に続いて、エピローグやAI COMMENTが表示されます。

## キーボード操作

Enterキーの動作は、現在の状態によって変わります。

| 状態 | Enterキーの動作 |
| --- | --- |
| 本文をタイピング表示中 | 残りの文章をすぐに全文表示 |
| 本文と選択肢の表示完了後 | 選択肢は画面上のボタンで決定します |
| AIが場面や音声を準備中 | 完了するまで選択操作は行えません |

タイピング中にEnterキーを押して全文表示しても、場面や選択結果が飛ばされることはありません。

## BAD ENDと再挑戦

誤った選択肢を選ぶと、次のようにBAD ENDが表示されます。

```text
=== BAD END ===
BAD ENDタイトル

その選択によって起きた結末
```

BAD END後は、次のどちらかを選べます。

### 「直前の選択肢へ」

BAD ENDになった場面へ戻り、もう一度2つの選択肢から選び直します。

- 場面本文は再生成されません。
- 選択肢も同じ内容です。
- 直前の状況を確認しながら、別の選択を試せます。
- その場面用に準備された音声キャッシュは、再挑戦に利用できるよう保持されます。  
（会話キャラクターを変更した場合、その変更したキャラクターによって音声が再生成されるため、時間がかかる場合があります）

### 「最初から」

現在の進行を終了し、最初の場面からゲームをやり直します。

※「最初から」を選んだ場合、**AIが新しく生成するため**前回とは異なる物語になります。

## GOOD ENDとAI COMMENT

5場面目で正しい選択をすると、次の内容が順番に表示されます。

1. 最終選択の結果
2. GOOD END
3. エピローグ
4. ゲームクリアメッセージ
5. AI COMMENT
6. プレイ記録

プレイ記録には、次の数値が使用されます。

- バッドエンド到達回数
- 「直前の選択肢へ」戻った回数
- 総選択回数

AI COMMENTは、プレイ記録をもとに、スムーズに攻略したか、試行錯誤したか、何度も挑戦してクリアしたかなどを踏まえて**AIの感想**が生成されます。

## VOICEVOX読み上げ

### 読み上げを使用する

1. VOICEVOXを起動します。
2. 「VOICEVOX読み上げ」をONにします。
3. 話者IDを半角数字で入力します。
4. ゲームを開始します。

初期話者IDは次のとおりです。

```text
3
```

別の声を使う場合は、VOICEVOX側でキャラクターとスタイルの話者IDを確認してください。

> [!IMPORTANT]
> 話者IDには半角数字を入力してください。

### 読み上げの仕組み

AIが生成した文章を適度な長さに分割し、VOICEVOXで順番にWAV音声へ変換します。

1. 本文の一部を受信
2. 読み上げやすい長さへ分割
3. VOICEVOXで音声を生成
4. 最初の音声完成後に、タイピング表示と再生を開始
5. 後続音声を順次生成・再生
6. 不要になった一時音声を削除

### 読み上げを停止する

「読み上げ停止」を押すと、再生中の音声と再生待ちの音声を停止します。

VOICEVOX ENGINEへすでに送信された通信処理は、すぐに終了しない場合があります。ただし、停止後に完成した音声は再生されません。

### VOICEVOXを起動していない場合

読み上げがONの状態でVOICEVOXへ接続できない場合は、警告を表示し、音声なしでゲームを続行します。

### 一時音声ファイル

生成した音声は、`voice_cache`フォルダへ一時的に保存されます。

音声キャッシュは、ゲーム進行、読み上げ停止、アプリ終了などに合わせて自動管理されます。通常、利用者が手動で操作する必要はありません。

## ジャンルと設定の編集

ゲーム設定は、次のファイルに保存されています。

```text
data/game_settings.json
```

### ジャンルを追加する

`genres`へ、ジャンル名と生成方針を追加します。

例：

```json
{
  "genres": {
    "日常コメディ": "身近な勘違いや小さな事件を扱う、明るく穏やかなコメディ。"
  }
}
```

実際に追加するときは、既存の`genres`内へ項目を加えてください。

左側が画面に表示されるジャンル名、右側がAIへ渡される物語の方向性です。

### JSON編集時の注意

- 項目と項目の間にはカンマが必要です。
- 最後の項目の後ろには、通常カンマを付けません。
- キーと値はダブルクォーテーション `"` で囲みます。
- JSON内にはコメントを書けません。
- UTF-8形式で保存してください。

書式が崩れると、アプリを正常に起動できなくなる場合があります。編集前にバックアップを作ることをおすすめします。

### 主な設定

| 設定 | 初期値 | 内容 |
| --- | ---: | --- |
| `game.total_scenes` | `5` | 物語の場面数 |
| `game.max_retries` | `3` | AI生成データの取得・解析に失敗した場合の再試行上限 |
| `game.summary_max_characters` | `100` | 場面間で引き継ぐ要約の最大文字数 |
| `ollama.default_model` | `gemma3:4b` | 初期モデル |
| `ollama.timeout_seconds` | `120` | Ollama通信のタイムアウト秒数 |
| `voicevox.speaker_id` | `3` | 初期話者ID |
| SE音量 | `20` | 効果音の初期音量 |

## 背景画像・BGM・効果音について

### 背景画像

場面ごとにAIが `background_tag` を選び、対応する背景画像が「情景窓」に表示されます。同じタグに複数の画像がある場合は、その中から画像が選ばれます。画像が見つからない場合でも、ゲーム進行を止めない設計です。

### BGM

場面ごとにAIが `bgm_tag` を選び、対応するBGMファイルが存在する場合に再生します。BGMは物語本文やVOICEVOXとは独立して音量を調整できます。

### 配布版の音源について

**v2の配布物には、権利上の理由からBGM・効果音などの音源ファイルを同梱しない予定です。**

BGMや効果音を使用したい場合は、利用者自身が使用権を確認した音源を用意し、アプリが参照する所定のファイル名へ変更して配置してください。音源が存在しない場合でも、物語生成・背景表示・VOICEVOXなど、音源以外の機能は利用できます。

> [!IMPORTANT]
> 追加する音源の著作権・利用規約・再配布条件は、各音源の権利者・配布元をご確認ください。

## トラブルシューティング

### Ollamaに接続できない

確認事項：

1. Ollamaがインストールされているか
2. Ollamaが起動しているか
3. `ollama serve`を実行できるか
4. 使用するモデルがダウンロード済みか
5. 接続先が`http://localhost:11434`になっているか

---

### モデル一覧が表示されない

1. Ollamaを起動します。
2. `ollama list`でモデルを確認します。
3. アプリの「モデル更新」を押します。

必要なモデルがない場合：

```bash
ollama pull gemma3:4b
```

---

### 場面生成が遅い

対処例：

- より軽量なモデルを選ぶ
- ThinkingをOFFにする
- PC上の負荷が高いアプリを終了する
- Ollamaを再起動する

場面はAIがその都度生成するため、通常の固定シナリオ型ゲームより待ち時間が発生します。

生成が失敗したまま進行できなくなった場合は、生成キャンセル機能を使って初期状態へ戻ることができます。

---

### 生成を何度もやり直している

モデルが、ゲームで必要なJSON形式を正しく返せていない可能性があります。

対処例：

- 指示追従性能の高いモデルへ変更する
- Ollamaを再起動する
- ThinkingのON／OFFを切り替える

内部の再試行上限は、初期設定で3回です。

---

### VOICEVOXに接続できない

確認事項：

1. VOICEVOXがインストールされているか
2. VOICEVOXが起動しているか
3. 「VOICEVOX読み上げ」がONか
4. 接続先が`http://127.0.0.1:50021`になっているか

VOICEVOXに接続できなくても、テキストのみでゲームを続けられます。

---

### 音声が再生されない

確認事項：

- PCがミュートになっていないか
- 正しい音声出力先が選ばれているか
- 話者IDが半角数字か
- 指定した話者IDが存在するか
- `pygame`がインストールされているか

---

### 読み上げ開始まで時間がかかる

本アプリは、最初の音声チャンクが完成してから本文表示と再生を始めます。

初回生成、文章の長さ、使用する話者、PC性能によっては、「物語を生成しています」の表示がしばらく続く場合があります。

音声が不要な場合は、「VOICEVOX読み上げ」をOFFにすると、音声生成を待たずに遊べます。

---

### Enterキーで選択肢を決定できない

本文がタイピング表示中の場合、Enterキーは「全文表示」として動作します。

本文と選択肢がすべて表示されたあとに、画面上の選択肢ボタンを押してください。

---

### `game_settings.json`のエラーで起動できない

確認事項：

- `data/game_settings.json`が存在するか
- カンマの不足や余分なカンマがないか
- キーと値がダブルクォーテーションで囲まれているか
- UTF-8形式で保存されているか

---

### 追加エンディングの生成に失敗した

エピローグやAI COMMENTの追加生成に失敗した場合は、固定メッセージへ切り替わります。

GOOD ENDまでの進行は失われず、ゲームはクリア扱いで終了します。
