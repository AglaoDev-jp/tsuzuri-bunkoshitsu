# 綴り文庫室 v3 利用マニュアル

**「選択で綴る、偶然の物語。」**  
**Ollama + VOICEVOXで遊ぶ、ローカルAIテキストアドベンチャーゲーム**  

「綴り文庫室」は、ローカル環境のAIがプレイごとに短い物語を作るテキストアドベンチャーゲームです。  

全5場面で表示される2つの選択肢ボタンから行動を選び、GOOD ENDを目指します。誤った選択でBAD ENDになっても、同じ場面へ戻って再挑戦できます。  

> [!NOTE]
> 本マニュアルは、アプリのソースコードおよび仕様をもとに、OpenAIの対話型AI「ChatGPT」の支援を受けて草案を作成し、作者が内容の確認・編集を行っています。  
> 本ソフトウェアは、同名または類似名称の既存の商標・製品・サービスとは関係ありません。

## ゲームの特徴

- Ollamaを利用し、ローカルLLMが物語を生成
- 30種類の登録ジャンル
- 文章で物語を指定できる「自由に綴る」モード
- 1ゲームは全5場面
- 各場面に2つの選択肢ボタン
- 正しい選択肢を選ぶと次の場面へ進行
- 誤った選択肢を選ぶと、その場面専用のBAD END
- BAD END後は同じ選択肢へ戻って再挑戦可能
- 最終場面の正解でGOOD END
- クリア後にエピローグ、GAME CLEAR、AI COMMENT、プレイ記録を表示
- 場面に応じた背景画像を表示する「情景窓」
- AIが場面に合う背景タグ・BGMタグを選択
- BGM・SE・VOICEの音量を個別に調整可能
- VOICEVOXによる読み上げに対応
- バックログの閲覧、プレイ記録と読み上げ音声の保存
- 物語生成が停止した場合の生成キャンセル

AIが場面を順番に生成するため、同じジャンルを選んでも、プレイするたびに登場人物や展開、結末が変化します。

## 動作環境

### 必須

- [Ollama](https://ollama.com/)
- Ollamaへダウンロード済みのモデル

実行ファイル版ではPythonとPythonライブラリは不要です。

Pythonソース版を使用する場合は、次の環境を推奨します。

- Python 3.10以上
- `requests`
- `pygame`

### 音声読み上げを使用する場合

- [VOICEVOX](https://voicevox.hiroshiba.jp/)
- 音声を再生できる環境

VOICEVOXを使用しない場合でも、テキストのみでゲームを遊べます。

## セットアップ

### 1. Ollamaをインストールする

[Ollama公式サイト](https://ollama.com/)からOllamaをインストールしてください。

### 2. 使用するモデルをダウンロードする

初期設定では、次のモデルが選択されます。

```text
gemma3:4b
```

モデルのダウンロード例：

```bash
ollama pull gemma3:4b
```

インストール済みモデルは、次のコマンドで確認できます。

```bash
ollama list
```

> [!NOTE]
> モデルによって、必要なメモリ、生成速度、日本語性能、JSON形式の指示への従いやすさが異なります。動作が重い場合は、より軽量なモデルをお試しください。

### 3. Ollamaを起動する

OllamaのAPIは、初期設定では次のアドレスで動作します。

```text
http://localhost:11434
```

接続できない場合は、ターミナルまたはコマンドプロンプトで次のコマンドを実行してください。

```bash
ollama serve
```

### 4. VOICEVOXをインストールする（任意）

音声読み上げを使用する場合は、VOICEVOXをインストールしてください。

- [VOICEVOX公式サイト](https://voicevox.hiroshiba.jp/)
- [VOICEVOX GitHub](https://github.com/VOICEVOX/voicevox)

VOICEVOX ENGINEは、初期設定では次のアドレスで動作します。

```text
http://127.0.0.1:50021
```

本アプリにVOICEVOX本体は含まれていません。読み上げを使用するときは、VOICEVOXを本アプリより先に起動してください。

### 5. Pythonライブラリをインストールする（Pythonソース版のみ）

```bash
python -m pip install requests pygame
```

WindowsのPython Launcherを使用する場合：

```bash
py -m pip install requests pygame
```

`tkinter` は通常、Pythonに同梱されています。

## 起動方法

本アプリは、実行ファイル版とPythonソース版のどちらからでも起動できます。

### 実行ファイル版から起動する

1. [GitHub Releases v3](https://github.com/AglaoDev-jp/tsuzuri-bunkoshitsu/releases/tag/v3)からWindows版のZIPファイルをダウンロードします。
2. ZIPファイルを任意の場所へ展開します。
3. Ollamaを起動します。
4. 読み上げを使用する場合は、VOICEVOXも起動します。
5. 展開したフォルダ内の `綴り文庫室.exe` をダブルクリックします。

```text
綴り文庫室/
├─ 綴り文庫室.exe
└─ _internal/
```

> [!IMPORTANT]
> `綴り文庫室.exe` だけを別の場所へ移動せず、`_internal` フォルダと同じ配布フォルダ内で起動してください。

実行ファイル版では、PythonおよびPythonライブラリを別途インストールする必要はありません。ただし、物語生成にはOllamaとダウンロード済みモデルが必要です。VOICEVOXは任意です。

初回起動時にWindowsやセキュリティソフトの確認画面が表示される場合があります。配布元とファイルを確認したうえで実行してください。

### Pythonソース版から起動する

リポジトリのルートから `src` フォルダへ移動し、`main.py` を実行します。

```bash
cd src
python main.py
```

WindowsのPython Launcherを使用する場合：

```bat
cd src
py main.py
```

正常に起動すると、「綴り文庫室」のウィンドウが表示されます。

起動直後は、ジャンル（または「自由に綴る」）とモデルを選び、「ゲーム開始」を押します。

| 項目 | 内容 |
| --- | --- |
| ジャンル | 生成する物語の種類、または「自由に綴る」を選びます |
| モデル | Ollamaにインストールされているモデルから、物語生成に使用するモデルを選びます |
| モデル更新 | Ollamaからインストール済みモデルの一覧を再取得します |
| VOICEVOX読み上げ | 本文を音声で読み上げるかを切り替えます |
| 話者ID | VOICEVOXで使用する声のIDを半角数字で指定します |
| BGM音量 | BGMの再生音量を0～100で調整します |
| SE音量 | 効果音の再生音量を0～100で調整します |
| VOICE音量 | VOICEVOX読み上げ音量を0～100で調整します |
| ゲーム開始 | 選択したジャンル、または入力した希望とモデルで新しいゲームを始めます |
| 直前の選択肢へ | BAD END後、同じ場面へ戻って再挑戦します |
| 生成キャンセル | 進行中のLLM生成を中止して初期状態へ戻ります |
| バックログ | 表示済みの物語を別ウィンドウで確認します |
| テキスト保存 | ゲームクリア後、プレイ記録をテキストファイルへ保存します |
| 音声保存 | ゲームクリア後、生成済みVOICEVOX音声を保存します |
| 音声停止 | 再生中および待機中の読み上げを停止します |

ゲーム開始後は、「ゲーム開始」ボタンの表示が「最初から」へ変わります。

- 格闘アクション
- ラブコメ

### 2. モデルを選ぶ

Ollamaにインストールされているモデルから、物語生成に使用するモデルを選びます。

### 3. 音声設定を確認する

VOICEVOXを使用する場合は、VOICEVOXを起動し、「VOICEVOX読み上げ」をONにします。音声が不要な場合はOFFにしてください。

必要に応じて、BGM・SE・VOICEの音量も調整します。

### 4. 「ゲーム開始」を押す

AIが第1場面を生成します。生成中は、次のような待機メッセージが表示されます。

```text
物語を生成しています...
```

点の数が変化しますが、正確な進捗率を示すものではありません。

### 5. 場面を読む

場面は、次のような形式で表示されます。

```text
--- 場面 1 / 5 ---
【場面タイトル】

物語の本文
```

選択肢は、本文欄ではなく画面下部の2つのボタンへ表示されます。

### 6. 選択肢ボタンを押す

本文の表示が完了すると、A・Bの選択肢ボタンが操作可能になります。選びたい行動のボタンをクリックしてください。

キーボードで `a`・`b` を入力する必要はありません。

### 7. 5場面目の正解を目指す

正しい選択を重ね、5場面目で正解するとGOOD ENDです。GOOD ENDのあとに、エピローグやAI COMMENTなどを順番に読み進めます。

## 「自由に綴る」で始める

ジャンル欄の末尾にある「自由に綴る」を選ぶと、普段は物語が表示される場所が専用の複数行入力欄へ切り替わります。

入力欄へ、遊びたい物語を一文または数文で自由に書いてください。ジャンル、舞台、主人公、雰囲気、目的などを個別の入力欄へ分ける必要はありません。

入力できる長さは1000文字までです。現在の文字数は入力欄の下に表示されます。

入力後は、通常モードと同じ「ゲーム開始」を押します。AIが入力内容を全5場面のゲーム向けに整理してから、第1場面を生成します。そのため、通常ジャンルより開始時のAI処理が1回多くなります。

開始設定や第1場面の生成に失敗した場合は、入力内容を残したまま専用画面へ戻ります。文章を修正して再試行できます。

生成中に「生成キャンセル」を押した場合も、入力内容は保持されます。

> [!NOTE]
> 自由入力欄でEnterキーを押すと、通常どおり改行できます。本文表示中のEnter操作とは区別されています。

## キーボード操作

Enterキーの動作は、現在の状態によって変わります。

| 状態 | Enterキーの動作 |
| --- | --- |
| 「自由に綴る」の入力欄を編集中 | 入力欄内で改行します |
| 本文をタイピング表示中 | 読み上げを停止し、残りの文章をすぐに全文表示します |
| 本文が全文表示済みで読み上げ中 | 残っている読み上げを停止します |
| 本文と選択肢の表示完了後 | 選択肢は画面上のボタンで決定します |
| AIが場面を生成中 | 完了するまで選択操作は行えません |

Enterキーを押しても、場面や選択結果が飛ばされることはありません。

---

## タイピング表示と音声

本文は1文字ずつ表示されます。読点、句点、改行では、通常の文字より少し長めの間を取ります。

VOICEVOX読み上げがONの場合は、最初の音声チャンクが完成してからタイピング表示と音声再生を開始します。後続の音声は順次準備されます。

本文の表示が完了するまでは、選択肢ボタンを押せません。

「音声停止」またはEnterキーで読み上げを停止しても、テキスト表示とゲーム進行は続けられます。

## 正解後の進み方

正しい選択肢を押すと、選んだ行動によって起きた結果が表示されます。

結果文の表示と読み上げが完了すると、選択肢欄に「次のシナリオへ」ボタンが表示されます。このボタンを押すまで、次の場面は表示されません。

自動で場面が切り替わらないため、結果文を読み終えてから、自分のタイミングで次へ進めます。

## BAD ENDと再挑戦

誤った選択肢を選ぶと、その場面の選択内容に対応したBAD ENDが表示されます。

```text
=== BAD END ===
BAD ENDタイトル

その選択によって起きた結末
```

BAD END後は、次のどちらかを選べます。

### 「直前の選択肢へ」

BAD ENDになった場面へ戻り、もう一度2つの選択肢から選び直します。

- 場面本文は再生成されません。
- 選択肢も同じ内容です。
- 直前の状況を確認しながら、別の選択を試せます。
- その場面用の読み上げ音声が残っている場合は、再挑戦時に利用されます。

### 「最初から」

現在の進行を終了し、第1場面から新しいゲームを始めます。

AIが物語を新しく生成するため、前回とは異なる展開になることがあります。

## GOOD ENDとAI COMMENT

5場面目で正しい選択をすると、次の内容が順番に表示されます。

1. GOOD END
2. EPILOGUE
3. GAME CLEAR
4. AI COMMENT
5. PLAY RECORD
6. 終了案内

GOOD ENDは「正解側の正規クリアエンディング」です。物語に応じて、大団円だけでなく、ほろ苦い結末、静かな別れ、代償を伴う勝利、余韻の残る結末などになる場合があります。

各項目は自動では進みません。次のボタンを順番に押して読み進めます。

- 「エピローグへ」
- 「GAME CLEAR」
- 「AI COMMENT」
- 「PLAY RECORD」
- 「最後に」

PLAY RECORDには、次の情報が表示されます。

- プレイ判定
- バッドエンド到達回数
- 「直前の選択肢へ」戻った回数
- 総選択回数

AI COMMENTは、物語とプレイ記録をもとに、今回の選択や展開をゲームマスターが短く振り返る文章です。

追加エンディングの生成に失敗した場合でも、固定メッセージへ切り替わり、ゲームはクリア扱いで終了します。

## モデル選択

### モデル一覧

本アプリは、Ollamaからローカルにインストールされているモデル一覧を取得します。

Ollamaを起動したあとにモデルを追加・削除した場合は、「モデル更新」を押してください。

### 初期モデル

初期設定は次のとおりです。

```text
gemma3:4b
```

`src/data/game_settings.json` の `ollama.default_model` で変更できます。

### モデル選びの注意

本アプリは、場面データをJSON形式で受け取ります。日本語生成ができても、JSON形式の指示へ安定して従えないモデルでは、生成を再試行したり、開始に失敗したりする場合があります。

大きなモデルほど必ず快適になるとは限りません。PCのメモリやVRAMに合ったモデルを選んでください。

## VOICEVOX読み上げ

### 読み上げを使用する

1. VOICEVOXを起動します。
2. 「VOICEVOX読み上げ」をONにします。
3. 話者IDを半角数字で入力します。
4. ゲームを開始します。

初期話者IDは次のとおりです。

```text
3
```

別の声を使う場合は、VOICEVOX側でキャラクターとスタイルの話者IDを確認してください。

> [!IMPORTANT]
> 話者IDには半角数字を入力してください。

### 読み上げの仕組み

AIが生成した文章を適度な長さに分割し、VOICEVOXで順番にWAV音声へ変換します。

1. 読み上げる文章を適度な長さへ分割
2. VOICEVOXで音声を生成
3. 最初の音声完成後にタイピング表示と再生を開始
4. 後続音声を順次生成・再生
5. ゲームの進行に合わせて音声キャッシュを管理

### 読み上げを停止する

「音声停止」を押すと、再生中の音声と再生待ちの音声を停止します。

VOICEVOX ENGINEへすでに送信された通信処理は、すぐに終了しない場合があります。ただし、停止後に完成した音声は再生されません。

### VOICEVOXを起動していない場合

読み上げがONの状態でVOICEVOXへ接続できない場合は、警告を表示し、音声なしでゲームを続行します。

### 一時音声ファイル

生成した音声は、アプリの `voice_cache` フォルダへ一時的に保存されます。

音声キャッシュは、ゲーム開始、読み上げ停止、アプリ終了などに合わせて管理されます。保存したい場合は、ゲームクリア後に「音声保存」を使用してください。

## 背景画像・BGM・効果音

### 背景画像

場面ごとにAIが `background_tag` を選び、対応する背景画像が「情景窓」に表示されます。

v3には65種類の背景タグと100枚の背景画像が収録されています。同じタグに複数画像がある場合は、その中から画像が選ばれます。

画像が見つからない場合でも、ゲーム進行は停止しません。

### BGM

場面ごとにAIが `bgm_tag` を選び、対応するBGMを再生します。

通常場面で使用するタグは次の7種類です。

- `calm`：静か・穏やか
- `bright`：明るい・楽しい
- `mystery`：謎・調査・違和感
- `tension`：緊迫・追跡・危機
- `battle`：戦闘・対決
- `sad`：悲しみ・別れ
- `horror`：怪異・恐怖

タイトル、エピローグ、GAME CLEARでは、専用のBGMを使用します。

BGMはループ再生され、場面に応じてフェードしながら切り替わります。同じBGMタグが続いた場合は、そのまま再生を継続します。

### 効果音

次の場面で効果音が再生されます。

- 正しい選択
- BAD END
- GOOD END

### 音量調整

BGM、SE、VOICEは個別に0～100で調整できます。調整結果は、現在再生中の音声にも反映されます。

### 音源を差し替える

音源は `src/assets/bgm/` と `src/assets/sfx/` にあります。同じファイル名で差し替えると、コードを変更せず別の音源を使用できます。

別の音源を使用する場合は、その音源のライセンス、利用規約、クレジット表記、再配布可否を確認してください。

## バックログと保存

### バックログを見る

「バックログ」を押すと、現在までに表示が完了した文章を別ウィンドウで確認できます。

次の内容が記録されます。

- 各場面の本文
- プレイヤーが選んだ選択肢
- 正解結果
- BAD END
- GOOD END以降の各項目

新しいゲームを開始すると、前回のバックログは消去されます。残したい場合は、ゲームクリア後にテキスト保存してください。

### プレイ記録をテキスト保存する

ゲームクリア後に「テキスト保存」を押します。保存先とファイル名を指定すると、UTF-8のテキストファイルとして保存されます。

保存内容には、次の情報が含まれます。

- 開始日時
- ジャンル
- 使用モデル
- バックログ全文

初期ファイル名には保存日時が付きます。

```text
綴り文庫室_プレイ記録_YYYYMMDD_HHMMSS.txt
```

### 読み上げ音声を保存する

VOICEVOX読み上げを使用してゲームをクリアすると、「音声保存」が使用可能になります。

1. 「音声保存」を押します。
2. 保存するフォルダ名を入力します。
3. 親フォルダを選びます。
4. 今回生成したWAVファイルが、再生順の連番付きで保存されます。

同じ名前のフォルダがすでに存在する場合は、別の名前を指定してください。

読み上げを使用していない場合や、保存できるWAVがない場合は、音声保存を利用できません。

## ジャンルと設定の編集

ゲーム設定は、次のファイルに保存されています。

```text
src/data/game_settings.json
```

### ジャンルを追加する

`genres` へ、ジャンル名と生成方針を追加します。

```json
{
  "genres": {
    "日常コメディ": "身近な勘違いや小さな事件を扱う、明るく穏やかなコメディ。"
  }
}
```

実際に追加するときは、既存の `genres` 内へ項目を加えてください。左側が画面に表示されるジャンル名、右側がAIへ渡される生成方針です。

### JSON編集時の注意

- 項目と項目の間にはカンマが必要です。
- 最後の項目の後ろには、通常カンマを付けません。
- キーと値はダブルクォーテーション `"` で囲みます。
- JSON内にはコメントを書けません。
- UTF-8形式で保存してください。

書式が崩れると、アプリを正常に起動できなくなる場合があります。編集前にバックアップを作ることをおすすめします。

### 主な設定

| 設定 | 初期値 | 内容 |
| --- | ---: | --- |
| `game.total_scenes` | `5` | 物語の場面数 |
| `game.max_retries` | `3` | AI生成データの取得・解析に失敗した場合の再試行上限 |
| `game.summary_max_characters` | `100` | 場面間で引き継ぐ要約の最大文字数 |
| `ollama.base_url` | `http://localhost:11434` | Ollama APIの接続先 |
| `ollama.default_model` | `gemma3:4b` | 初期モデル |
| `ollama.timeout_seconds` | `120` | Ollama通信のタイムアウト秒数 |
| `voicevox.base_url` | `http://127.0.0.1:50021` | VOICEVOX ENGINEの接続先 |
| `voicevox.speaker_id` | `3` | 初期話者ID |
| `voicevox.volume` | `1.0` | VOICEの初期音量 |
| `sfx.volume` | `0.2` | SEの初期音量 |
| `bgm.volume` | `0.2` | BGMの初期音量 |
| `bgm.fade_ms` | `800` | BGM切り替え時のフェード時間（ミリ秒） |

## トラブルシューティング

### Ollamaに接続できない

確認事項：

1. Ollamaがインストールされているか
2. Ollamaが起動しているか
3. `ollama serve` を実行できるか
4. 使用するモデルがダウンロード済みか
5. 接続先が `http://localhost:11434` になっているか

### モデル一覧が表示されない

1. Ollamaを起動します。
2. `ollama list` でモデルを確認します。
3. アプリの「モデル更新」を押します。

必要なモデルがない場合：

```bash
ollama pull gemma3:4b
```

### 場面生成が遅い

対処例：

- より軽量なモデルを選ぶ
- PC上の負荷が高いアプリを終了する
- Ollamaを再起動する
- VOICEVOX読み上げをOFFにして待ち時間を比較する

「自由に綴る」は、開始時に入力内容をゲーム設定へ整理するため、通常ジャンルよりAI処理が1回多くなります。

生成を待ち続けられない場合は、「生成キャンセル」で初期状態へ戻れます。

### 生成を何度もやり直している

モデルが、ゲームで必要なJSON形式を正しく返せていない可能性があります。

対処例：

- JSON形式の指示へ従いやすいモデルへ変更する
- Ollamaを再起動する
- 「自由に綴る」の入力を短く整理する

内部の再試行上限は、初期設定で3回です。

### 「自由に綴る」でゲームを開始できない

確認事項：

- 入力欄が空になっていないか
- 1000文字を超えていないか
- 選択したモデルがOllamaで利用できるか
- モデルがJSON形式の指示へ対応できるか

エラー後も入力内容は保持されます。文章を修正して再試行してください。

### VOICEVOXに接続できない

確認事項：

1. VOICEVOXがインストールされているか
2. VOICEVOXが起動しているか
3. 「VOICEVOX読み上げ」がONか
4. 接続先が `http://127.0.0.1:50021` になっているか

VOICEVOXに接続できなくても、テキストのみでゲームを続けられます。

### 音声が再生されない

確認事項：

- PCがミュートになっていないか
- 正しい音声出力先が選ばれているか
- 話者IDが半角数字か
- 指定した話者IDが存在するか
- Pythonソース版では `pygame` がインストールされているか
- VOICE音量が0になっていないか

### BGM・効果音が再生されない

確認事項：

- BGM音量またはSE音量が0になっていないか
- `src/assets/bgm/` と `src/assets/sfx/` に音源が存在するか
- 音源のファイル名を変更していないか
- PCの音声出力が正しく設定されているか

音源が見つからない場合でも、ゲームは続行します。

### 読み上げ開始まで時間がかかる

本アプリは、最初の音声チャンクが完成してから本文表示と再生を始めます。

初回生成、文章の長さ、使用する話者、PC性能によっては、待機表示がしばらく続く場合があります。

音声が不要な場合は、「VOICEVOX読み上げ」をOFFにすると、音声生成を待たずに遊べます。

### Enterキーで選択肢を決定できない

Enterキーは、本文の全文表示または音声停止に使用します。選択肢の決定には、画面下部のA・Bボタンを使用してください。

### 「次のシナリオへ」が表示されない

正解結果のタイピング表示と、VOICEVOX読み上げがONの場合は読み上げ処理の完了を待ってください。

読み上げを待たずに進みたい場合は、「音声停止」を押してください。

### テキスト保存・音声保存が押せない

保存機能は、最後の終了案内まで表示してゲームクリア処理が完了したあとに有効になります。

音声保存は、VOICEVOXで生成されたWAVファイルが存在する場合だけ有効になります。

### `game_settings.json` のエラーで起動できない

確認事項：

- `src/data/game_settings.json` が存在するか
- カンマの不足や余分なカンマがないか
- キーと値がダブルクォーテーションで囲まれているか
- UTF-8形式で保存されているか

### 追加エンディングの生成に失敗した

エピローグやAI COMMENTの追加生成に失敗した場合は、固定メッセージへ切り替わります。GOOD ENDまでの進行は失われず、ゲームはクリア扱いで終了します。
