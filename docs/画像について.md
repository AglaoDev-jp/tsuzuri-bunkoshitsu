# 背景画像の追加方法

背景画像は `background_tag` ごとに自動検索されます。
既存画像を追加・差し替えするだけなら、Pythonコードの修正は不要です。

## 1枚だけ使用する場合（従来方式）

タグと同じ名前で、背景フォルダの直下へ置きます。

```text
assets/backgrounds/forest.jpg
assets/backgrounds/forest.png
```

同名のJPG・JPEG・PNGが複数ある場合は、JPG、JPEG、PNGの順に1枚を使用します。

## 同じタグへ複数画像を追加する場合（推奨）

タグと同じ名前のフォルダを作り、その中へ画像を追加します。
フォルダ内の画像名は自由です。

```text
assets/backgrounds/
├─ forest.png
└─ forest/
   ├─ forest_path_01.jpg
   ├─ forest_clearing_01.jpg
   └─ forest_path_02.jpg
```

`forest.png` と `forest/` 内の画像が、すべて `forest` の候補になります。
場面ごとに候補から選ばれ、複数ある場合は直前と同じ画像を避けます。

サブフォルダを作らず、次のように追加することもできます。

```text
assets/backgrounds/forest__path.jpg
assets/backgrounds/forest__clearing.jpg
```

タグ名と任意名の間は、アンダースコア2個（`__`）にしてください。

同じタグの候補はランダムに選ばれます。本文との矛盾を避けるため、
昼・真夜中・豪雨など、条件が大きく異なる画像を同じタグへ混在させないでください。
同じ場所として違和感なく置き換えられる構図違いを登録するのが安全です。

## 新しいタグを追加する場合

1. `game_prompts.py` の `BACKGROUND_TAG_DESCRIPTIONS` へタグと説明を1行追加する
2. 同名画像または同名フォルダを `assets/backgrounds/` へ追加する

`main.py` や `game_engine.py` の修正は不要です。

## 対応形式

- `.jpg`
- `.jpeg`
- `.png`

画像が見つからない、または読み込めない場合も、ゲームは停止せず無地の情景窓で続行します。
